Repositori resmi untuk website **Syah Group**, sebuah *holding company* modern yang menaungi berbagai pilar bisnis di bidang Alat Berat, Teknologi Informasi, dan Multimedia. Website ini dirancang dengan fokus pada performa tinggi, desain antarmuka yang mewah (konglomerat-style), dan pengalaman pengguna yang interaktif.

## 🌟 Pilar Bisnis Kami
1. **Syah Heavy Equipment** - Jual beli dan perbaikan alat berat kelas industri.
2. **Syah Tech** - Solusi Teknologi Informasi, pengembangan Software, dan pengadaan Hardware.
3. **Syah Studio** - Layanan Multimedia, Fotografi, Videografi, dan *Post-production*.

## 🚀 Tech Stack
Proyek ini dibangun menggunakan teknologi web modern:
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion & GSAP (ScrollTrigger)
- **Smooth Scroll:** Lenis by Studio Freight
- **Database & Storage:** PostgreSQL + Storage by Supabase

## 📂 Struktur Proyek
```text
├── src
│   ├── app           # Next.js App Router (Pages, Layouts, API Routes)
│   ├── components    # Reusable UI components (Hero, Cards, Footer, dll)
│   ├── lib           # Konfigurasi Supabase, Utility functions
│   ├── styles        # Global styles & Tailwind config
│   └── types         # TypeScript type definitions
├── public            # Asset statis (Images, Videos, Icons)
└── README.md
```
